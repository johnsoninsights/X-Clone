# X Clone — Social Media Platform Built with Next.js & Firebase

A modern clone of the social platform **X**, built with **Next.js**, **React**, **Firebase Authentication**, and **TypeScript**.  
This project demonstrates secure auth flows, responsive UI, and a dynamic tweet feed using a clean, scalable frontend architecture.

---

## 🚀 Features

- **User Authentication**
  - Sign Up, Login, Logout
  - Firebase Authentication (Email/Password)
  - Persistent sessions and protected routes

- **Tweet Feed**
  - Post and view tweets
  - Real-time updates (if using Firestore)
  - Clean, responsive feed layout

- **Modern Frontend Stack**
  - Built with **Next.js** and **React**
  - Fully typed with **TypeScript**
  - Styled using **CSS**, **SCSS**, and modular components
  - Mobile
